# TalentRank AI Frontend

## Project Overview
A polished, production-style frontend for an AI resume ranking system built for recruiters. It includes landing, auth, dashboard, job management, candidate review, resume upload, AI ranking results, analytics, notifications, profile, settings, and a 404 experience.

## Folder Structure
- src/components: shared layout and reusable UI shell
- src/pages: all application pages
- src/data: realistic sample data
- src/styles: global styling

## How to run the frontend
1. cd frontend
2. npm install
3. npm run dev
4. Open http://localhost:3000
